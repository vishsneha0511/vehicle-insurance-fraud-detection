# 🚗 Vehicle Insurance Fraud Detection using Machine Learning

## 📌 Project Overview

This project develops an end-to-end machine learning pipeline to detect fraudulent vehicle insurance claims using historical claim data. The workflow includes data preprocessing, class imbalance handling using SMOTE, model comparison, hyperparameter tuning, model evaluation, and feature importance analysis to identify the most effective fraud detection model.
